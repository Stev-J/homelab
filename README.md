# Homelab – Steven Jacques

Laboratoire personnel d'entraînement et de documentation technique.
Chaque dossier correspond à un lab autonome : contexte, schéma, configurations, tests et retour d'expérience.

Objectif : entretenir et démontrer des compétences concrètes de technicien systèmes et réseaux, sur des cas proches de ce qu'on rencontre en PME.

## Environnement

- VMware Workstation sur poste personnel
- PNETLab pour la partie réseau (images Cisco IOSv, FortiGate, ASA)
- VM Windows Server 2022, Windows 11, Debian 12, Kali Linux

## Conventions

- Plages IP privées uniquement, aucun élément issu d'un environnement professionnel
- Comptes et noms fictifs
- Chaque README contient une section « Problèmes rencontrés » — c'est souvent la partie la plus utile
